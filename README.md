## 3. Цели и задачи сайта

### Цели:
- Популяризация джиу-джитсу как доступного вида спорта для всех возрастов
- Объединение региональных федераций, клубов и спортсменов
- Предоставление актуальной информации о соревнованиях и семинарах

### Задачи:

| Задача | Как реализуется на сайте |
|--------|-------------------------|
| Показать историю для изучения | Раздел «История» с хронологией ключевых событий |
| Рассказать о сильных спортсменах и тренерах | Каталог «Звёзды российского джиу-джитсу» с биографиями и достижениями |
| Помочь найти клуб рядом с домом | Интерактивная карта клубов с поиском по городу |
| Оповещать о турнирах | Календарь соревнований с фильтрацией по дате, региону и уровню |
| Мотивировать начинающих | Блог с обучающими статьями и видео (базовая техника, терминология, советы) |

### Связь цели и контента:

| Цель | Какой контент это реализует |
|------|---------------------------|
| Популяризация | Статьи о том, как джиу-джитсу меняет жизнь (интервью с родителями детей-спортсменов) |
| Объединение регионов | Раздел «Клубы и контакты», где любой тренер может добавить свою секцию через форму |

## 4. Целевая аудитория

| Тип пользователя | Потребности |
|-----------------|-------------|
| Начинающие (подростки 9–17 лет) | Узнать основы, найти ближайшую секцию, посмотреть видеоуроки |
| Родители | Понять, безопасен ли спорт, записать ребёнка, увидеть достижения детей |
| Спортсмены-любители (18–35 лет) | Найти турниры, повысить уровень |
| Тренеры и организаторы | Опубликовать турнир, найти спонсоров, поделиться опытом |

### Как аудитория отличается от общей:
- Высокий интерес к здоровому образу жизни и самодисциплине
- Ценят факты, статистику и конкретику («синий пояс за 2 года» вместо абстрактных «успехов»)
- Многие знают английскую терминологию (mount, armbar, kimura), но ценят перевод и пояснения

### Как привлекаем внимание:
- **Для начинающих:** «Первые 3 месяца — как не бросить?» — гайд с пошаговым планом
- **Для родителей:** рейтинг лучших детских клубов по субъектам РФ
- **Для спортсменов:** таблица рейтингов спортсменов по версии федерации

## 5. Структура сайта

- **Главная**
  - Топ-новость (например, «Россиянин взял золото на IBJJF — подробности»)
  - Ближайшие турниры (виджет: город, дата, регистрация)
  - Клуб месяца (интервью и видео)

- **История джиу-джитсу в России**
  - Хронология (ключевые события)
  - Ветераны движения

- **Карта клубов**
  - Поиск по городу
  - Фильтр: детские группы / цена
  - Карточка клуба с отзывами

- **Турниры и мероприятия**
  - Календарь
  - Регистрация онлайн
  - Результаты прошедших турниров

- **База знаний**
  - Словарь терминов
  - Схемы позиций
  - Видеоуроки по поясам

- **Звёзды российского джиу-джитсу**
  - Топ-10 мужчин
  - Топ-10 женщин
  - Перспективная молодёжь

- **Личный кабинет**
  - Избранные клубы
  - Запись на турниры
  - Заявка на добавление клуба
